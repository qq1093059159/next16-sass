# 深入理解 SSG 与 ISR

## 生成阶段

`generateStaticParams()` 返回的每个值都会在构建期被预渲染成独立 HTML。

## 再生成阶段

超过 `cacheLife` 的 revalidate 时间后，Next 在后台重新生成页面（用户仍看到旧内容）。

```tsx
async function getPost(id: string) {
  "use cache";
  cacheLife({ stale: 30, revalidate: 60, expire: 3600 });
  cacheTag(`post-${id}`);
  return posts.find((p) => p.id === id);
}
```
