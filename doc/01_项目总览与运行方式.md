# 第 01 课 · 项目总览与运行方式

> **学习目标**：搞清楚这个仓库是什么、不是什么，以及怎么把它跑起来。
> **对应代码**：仓库根目录、`next.config.ts`、`app/layout.tsx`
> **预计耗时**：15 分钟

## 一、这是什么

`next16-sass` 是一个 **教学型实验田**，不是业务脚手架。

它把 Next.js 16 App Router 的每一项核心机制，都做成了**可点击验证的最小样本**。
其中大量样本被刻意做成 **两两对照组** —— 两份几乎相同的代码并排放，让你亲眼看出差异，
而不是读文档想象。

| 维度 | 结论 |
|---|---|
| **是什么** | Next.js 16 特性地图 + 反模式对照表 + 实测踩坑清单 |
| **不是什么** | ❌ 生产级 SaaS 模板（路由守卫生写 `useEffect`、鉴权是硬编码 token） |
| | ❌ 最佳实践范本（代码里多处标注「仅供演示 非最佳实践」） |
| **技术底座** | Next.js 16.3.8 · React 19.3.0 · Tailwind CSS v4 · TypeScript 5 · Turbopack |
| **规模** | 60+ 个路由目录 · 27 个知识点主题 · 59 个构建产物页面 |

仓库根目录的 `README.md` 是**唯一**的项目说明文档（原 `项目分析.md` 已合并删除）。
本 `doc/` 目录是它的**教学化拆解** —— 一次一个知识点，带实验步骤。

## 二、五分钟跑起来

### 环境要求

| 依赖 | 版本 | 必需性 |
|---|---|---|
| Node.js | ≥ 20.9（推荐 22+） | ✅ 必需 |
| pnpm | ≥ 9 | ✅ 必需（仓库用 `pnpm-lock.yaml`） |
| DeepSeek API Key | — | ⚠️ 仅 AI 功能需要 |

### 启动

```bash
pnpm install
pnpm dev          # → http://localhost:3000
```

其他脚本：

```bash
pnpm build        # 生产构建（会跑 TypeScript 检查 + 静态预渲染）
pnpm start        # 启动生产服务
pnpm lint         # ESLint 检查
```

> `dev` 与 `build:prod` 的差异：`pnpm dev` 注入 `DB_HOST=localhost`，
> `pnpm build:prod` 注入 `DB_HOST=8.8.8.8`。这两条脚本是配合 `/env` 页面
> 演示**构建期内联 vs 运行时读取**的开关，别当成真实配置手段。

### 环境变量

新建 `.env.local`（仓库未提供，自行创建），按需填写：

```bash
# AI 相关（仅 AI 章节需要）
DEEPSEEK_API_KEY="填你的 key"

# Clerk 相关（当前未接线，仅占位路由）
# NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=""
# CLERK_SECRET_KEY=""
```

> ⚠️ **安全提醒**：只有 **`NEXT_PUBLIC_` 前缀**的变量会被打进浏览器包。
> 密钥类变量（API Key、DB 密码）**绝不能**加这个前缀。

## 三、启动前必知的三个坑

| 现象 | 原因 | 解决 |
|---|---|---|
| Turbopack 改文件后嵌套路由偶发 404 | dev 期文件系统缓存错乱 | **先停 `dev`**，再删掉 `.next` 目录重启。**切勿在 dev 运行时删 `.next`** |
| 构建报 `Route segment config "dynamic" is not compatible with nextConfig.cacheComponents` | 开了 Cache Components 后段级配置被禁用 | 改用 `await connection()`，见第 10 课 |
| 访问 `/mdx-page` 404 | `next.config.ts` 的 `pageExtensions` 被注释 | 取消注释并用 `withMDX()` 包裹 |

## 五、动手实验（第一课）

### 实验 1：跑起来

```bash
pnpm install
pnpm dev
```

打开 <http://localhost:3000>，你应该看到首页（`app/(root)/page.tsx`），
顶部有 Navbar，右上角有暗黑模式切换。

### 实验 2：打开知识点地图

打开 <http://localhost:3000/knowledge>。

你会看到 9 大主题、50+ 个知识点，每一条都标注了**对应的代码文件位置**，
大部分带跳转链接。这是本仓库的**总索引**，学任何东西前先在这里定位。

### 实验 3：看构建产物形态

```bash
pnpm build 2>&1 | sed -n '/Route (app)/,/Proxy/p'
```

你会看到三种标记，这是理解 Next 16 渲染模型的钥匙：

```text
┌ ○ /about              ← 全静态：构建期就生成了 HTML
├ ◐ /albums             ← 部分预渲染（PPR）：静态壳子 + 流式动态内容
└ ƒ /api/user           ← 全动态：每次请求服务端渲染
```

> **本课结论**：先记住这三种标记。第 9~12 课会逐一讲清它们。

## 七、小结 & 下一步

- 这个仓库是**实验田**，不是模板。用法是「改一行 → 刷新浏览器 → 看框架反应」。
- 三种构建标记（`○`/`◐`/`ƒ`）是后面所有缓存知识的前提。
- 环境变量只有 `NEXT_PUBLIC_` 前缀会进浏览器包。
